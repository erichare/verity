## Compatibility and scientific interpretation

Correcting recipe metadata changes affected content handles even when numerical
results are unchanged. Reproducing a historical handle requires its corresponding
code revision, inputs, configuration, and reference.

Validity-mask support intentionally changes decoded data for files whose valid-point
mask was previously ignored. Published headline figures remain historical results.
The available original fixture, `csafe-logo.x3p`, has no separate validity mask.
The full source datasets and catalog raw blobs are absent from this checkout, so this
sweep cannot claim a complete rerun of the published scientific validation. See the
decoder impact note in [the number registry](headline-numbers.md) and the new
[validity fixtures](../tests/fixtures/README.md). Scoring and calibration algorithms
were not changed.

The compute timeout limits how long a request waits. Python cannot terminate an
already-running worker thread. Its capacity remains occupied until it finishes,
preventing timed-out work from allowing an unbounded queue to accumulate.
